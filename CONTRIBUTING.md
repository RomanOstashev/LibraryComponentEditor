# Работа с ветками

1. Создайте ветку от актуальной `main` для каждой задачи. Используйте `feat/`, `fix/` или `docs/`, например `feat/open-editor-window`.
2. Откройте pull request в `main`. Пока работа идёт, используйте черновик. Если есть Issue, свяжите его с PR.
3. Опишите проверку в PR. Для изменений в плагине укажите, как проверить результат на Windows в Renga.
4. После проверки используйте Squash and merge и удалите ветку задачи. Все изменения в `main` вносятся через PR.

Проверенные выпуски отмечаем тегами `vX.Y.Z` и публикуем через GitHub Releases. Проверку сборки на Windows добавим после появления собираемого проекта.
