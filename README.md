# Library Component Editor для Renga

**Library Component Editor для Renga** — визуальный редактор параметрических шаблонов стилей Renga STDL.

Пользователь строит форму из геометрических примитивов и применяет операции, поддерживаемые Renga STDL. Каждое построение отражается в программе Lua и в 3D-виде. Параметры и порты описываются в конфигурации JSON. Для импорта в Renga исходники собираются в файл RST.

Первая область применения — инженерное оборудование. Следующий этап — поддержка арматурных изделий и шаблонов армирования.

## Проверка плагина в Renga 9.4.34553

Текущая сборка добавляет на верхнюю панель Renga кнопку **Library Component Editor**. Она открывает немодальное окно с примерами элементов WPF. Введённые значения существуют только в этом окне.

1. Скачайте артефакт **LibraryComponentEditor** со страницы проверки **Windows preview** в pull request. В свойствах загруженного ZIP нажмите «Разблокировать», если Windows показывает этот флажок. Извлеките файлы в папку `LibraryComponentEditor`.
2. В этой папке выполните команду в 64-разрядной Windows PowerShell. Скрипт загрузит Renga SDK с сайта разработчика, проверит версию его файлов и подготовит две библиотеки для плагина.

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Prepare-RengaRuntime.ps1
   ```

   Если у вас уже распакован Renga SDK 2.51, добавьте к команде `-SdkDirectory "C:\SDK\RengaSDK"`. Visual Studio и RstBuilder для запуска окна не требуются.

3. Закройте Renga и скопируйте подготовленную папку в `Plugins` каталога установки Renga Professional. Проверьте вложенность по файлу `Plugins\LibraryComponentEditor\LibraryComponentEditor.rndesc`.
4. Запустите Renga, откройте проект и нажмите кнопку со стандартным значком приложения Windows. Окно должно развернуться на мониторе Renga. Проверьте сворачивание, восстановление, изменение размера и возврат в модель через панель задач. Повторное нажатие кнопки возвращает открытый редактор. После закрытия крестиком кнопка открывает новое окно.
5. Запустите второй экземпляр Renga и откройте редактор в нём. При наличии второго монитора сначала перенесите на него вторую Renga. Закрытие одного экземпляра должно оставить доступными второй экземпляр и его окно.

## Сборка из исходников

Для сборки на Windows x64 установите .NET SDK 8 или новее и .NET Framework 4.8 Developer Pack. Выполните команду в корне репозитория.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```

Готовые файлы для проверки находятся в `artifacts\LibraryComponentEditor`. Для установки выполните шаги 2–5. После подготовки зависимостей проект `src\LibraryComponentEditor\LibraryComponentEditor.csproj` также открывается в Visual Studio 2022.
